# 06 — Справочники (seed)

Заполняются идемпотентно:

```bash
uv run python -m scripts.seed_dicts
```

Повторный запуск не создаёт дублей: записи сопоставляются по `slug`,
название обновляется при изменении.

## Подходы (`approaches`) — 5

| slug | name |
| --- | --- |

| `act` | Терапия принятия и ответственности (ACT) |
| `psychodynamic` | Психодинамическая терапия |
| `systemic` | Системная семейная терапия |
| `gestalt` | Гештальт-терапия |
